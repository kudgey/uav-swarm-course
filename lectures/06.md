# Модуль 06 · Багатоагентне навчання: моделі та виклики

Два дрони летять назустріч вузьким коридором, і розминутися можна лише в одному місці: що робити кожному, залежить від іншого. Лекція будує мову для таких задач і показує на прогонах, чому вчитися поруч з іншим агентом складніше, ніж наодинці.

Джерело: [Albrecht, Christianos, Schäfer, *Multi-Agent Reinforcement Learning*, MIT Press, 2024](https://www.marl-book.com/), рис. 1.3. $n$ агентів отримують спостереження й винагороди (*observation & reward*), їхні дії (*action*) складаються у спільну дію (*joint action*), яка змінює стан середовища (*environment*).

### Зміст лекції

Багатоагентне навчання з підкріпленням (*multi-agent reinforcement learning*, MARL) має дві складові: **модель гри** — хто що бачить, які дії доступні, від чого залежить винагорода, — і **концепцію розв'язку** — яку спільну поведінку вважати доброю. Усю лекцію тримаємося однієї задачі: два дрони в коридорі з кишенею.

| **Частина** | **Про що** |
|---|---|
| 1 | п'ять моделей ігор на одному коридорі |
| 2 | як читати матрицю, рівновага Неша на пальцях, чотири класичні ігри |
| 3 | очікувана віддача, мінімакс, Парето, добробут і справедливість — у таблицях |
| 4 | одна таблиця на двох проти своєї в кожного: прогін у коридорі |
| 5 | чотири виклики MARL, кожен — прикладом і числом |

### Результати навчання

Після лекції ви зможете:

- розрізнити MDP, POMDP, стохастичну гру, POSG і Dec-POMDP і показати кожну на коридорі;
- знайти рівновагу Неша в матриці 2 × 2 підкресленням найкращих відповідей, а ймовірнісну — з умови байдужості;
- порахувати очікувану віддачу ймовірнісної політики, мінімакс, Парето-оптимальні клітинки, добробут і справедливість;
- пояснити, чим централізоване навчання відрізняється від незалежного;
- назвати чотири виклики MARL і для кожного навести приклад і число з прогону.

### Наскрізна задача: два дрони в коридорі

Два апарати обстежують тунель і мають помінятися кінцями. Розминутися можна лише через **кишеню** — нішу над середньою клітинкою.

Коридор із п'яти клітинок 0–4 і кишенею K над клітинкою 2. Синій дрон у клітинці 0 летить праворуч до виходу, помаранчевий у клітинці 4 — ліворуч. Блакитна смуга над клітинками 0–1 — що бачить сенсор синього з радіусом 1. Поруч правила: дії вперед, чекати, кишеня; −1 за крок кожного дрона, −50 за зіткнення, винагорода спільна

</Figure>


- Ряд із п'яти клітинок 0–4 і кишеня K над клітинкою 2. Синій летить праворуч, помаранчевий — ліворуч.
- Кожен крок обидва **одночасно** обирають «вперед», «чекати» або «кишеня» (пірнути в кишеню можна лише з клітинки 2).
- Обидва в одній клітинці або пролетіли одне крізь одне — зіткнення, політ закінчується.
- Винагорода **спільна**, одна на двох: −1 за кожен крок кожного дрона в коридорі, −50 за зіткнення.

Ось ядро моделі — один спільний крок:


<CodeFold title="Правила коридору: один спільний крок двох дронів" :lines="9" fragment>

```python
def step(s, a):
    """s = (синій, помаранчевий), a = (дія синього, дія помаранчевого)."""
    new = (move(0, s[0], a[0]), move(1, s[1], a[1]))  # кожен за своєю дією
    same = new[0] == new[1] != HOME  # в одній клітинці
    swap = new[0] == s[1] != HOME and new[1] == s[0] != HOME  # крізь одне одного
    if same or swap:
        return new, -50.0, True  # зіткнення
    flying = sum(p != HOME for p in s)  # скільки дронів ще в коридорі
    return new, -1.0 * flying, new == (HOME, HOME)  # кінець, коли вилетіли обидва
```

</CodeFold>


Наслідок дії залежить від **спільної дії**: «вперед» для синього добре, якщо помаранчевий чекає, і катастрофа, якщо той теж летить уперед. Саме цієї залежності не було в модулях 04–05.

### Стан і спостереження

Симулятор знає **стан** — місця обох дронів. Кожен дрон знає лише **спостереження** — те, що ловить його сенсор радіусом 1: власна клітинка й дві сусідні.

Невидимі клітинки сірі.">

Той самий стан (1, 3) трьома очима: симулятор бачить обидва дрони; синій бачить клітинки 0–2 і кишеню, а помаранчевого не бачить; помаранчевий бачить клітинки 2–4 і кишеню, а синього не бачить. Невидимі клітинки сірі.

</Figure>


Один крок у даних:

| **Стан (синій, помаранчевий)** | **Бачить синій** | **Бачить помаранчевий** | **Дії** | **r** |
|---|---|---|---|---|
| (1, 3) | себе в 1, іншого не видно | себе в 3, іншого не видно | вперед / чекати | −2 |
| (2, 3) | себе в 2, іншого в 3 | себе в 3, іншого в 2 | — | — |

Винагорода −2, бо в коридорі обидва. Від того, що доступно агентові — стан чи спостереження — і чи винагорода в нього своя, залежить модель гри.


<CodeFold title="Коридор: два дрони, повна модель і один крок" :lines="48" sec="0.0" check>

```python
import itertools

K, HOME = 5, 6  # клітинки ряду 0–4, кишеня над клітинкою 2, «вилетів»
DIR, START = (+1, -1), (0, 4)  # синій летить праворуч, помаранчевий — ліворуч
ACTS = ("вперед", "чекати", "кишеня")
STEP_COST, CRASH = -1.0, -50.0  # за крок кожного дрона в коридорі; за зіткнення
JOINT = list(itertools.product(range(3), repeat=2))  # 9 спільних дій


def move(i, p, a):
    """Нове місце дрона i з місця p після дії a, без перевірки зіткнень."""
    if p == HOME:
        return HOME
    if p == K:
        return 2 if a == 0 else K  # «вперед» з кишені — назад у клітинку 2
    if a == 0:
        q = p + DIR[i]
        return HOME if q < 0 or q > 4 else q
    return K if a == 2 and p == 2 else p  # «кишеня» деінде — те саме, що чекати


def step(s, a):
    """Спільний крок: стан (p0, p1), спільна дія (a0, a1) → (s′, r, кінець)."""
    new = (move(0, s[0], a[0]), move(1, s[1], a[1]))
    flying = sum(p != HOME for p in s)
    same = new[0] == new[1] != HOME
    swap = new[0] == s[1] != HOME and new[1] == s[0] != HOME
    if same or swap:
        return new, CRASH, True
    return new, STEP_COST * flying, new == (HOME, HOME)


def see(i, s, radius=1):
    """Спостереження дрона i: своє місце і чуже, лише якщо воно ближче за radius."""
    x = [2 if p == K else p for p in s]  # кишеня — над клітинкою 2
    near = HOME not in s and abs(x[0] - x[1]) <= radius
    return (s[i], s[1 - i] if near else "не видно")


STATES = [
    s for s in itertools.product(range(7), repeat=2) if s[0] != s[1] or s[0] == HOME
]
print(f"станів {len(STATES)}, дій у дрона {len(ACTS)}, спільних дій {len(JOINT)}")
s, a = (1, 3), (0, 1)
s2, r, done = step(s, a)
print("стан  спостереження синього / помаранчевого   дії            → стан  r")
print(f"{s}  {see(0, s)} / {see(1, s)}   {ACTS[a[0]]}/{ACTS[a[1]]} → {s2}  {r:+.0f}")
print(f"{s2}  {see(0, s2)} / {see(1, s2)}")
```

## Частина 1 · Моделі ігор

П'ять моделей відрізняються відповідями на три питання: скільки агентів, що бачить агент і чия винагорода.

| **Модель** | **Агентів** | **Агент бачить** | **Винагорода** | **На коридорі** |
|---|---|---|---|---|
| MDP | 1 | стан | своя | один дрон у порожньому коридорі |
| POMDP | 1 | спостереження | своя | один дрон із сенсором |
| стохастична гра | кілька | стан | у кожного своя | два дрони, кожен бачить усе й рахує свій час |
| POSG | кілька | спостереження | у кожного своя | два дрони з сенсорами |
| Dec-POMDP | кілька | спостереження | спільна | два дрони з сенсорами, одна винагорода — задача лекції |


<Figure src="/figs/own/mod06-models.png" msrc="/figs/own/mod06-models-m.png" alt="Схема моделей ігор: від MDP додаванням спостережень отримуємо POMDP, додаванням агентів — стохастичну гру; разом вони дають POSG, а POSG зі спільною винагородою — Dec-POMDP, модель коридору лекції.">

Схема моделей ігор: від MDP додаванням спостережень отримуємо POMDP, додаванням агентів — стохастичну гру; разом вони дають POSG, а POSG зі спільною винагородою — Dec-POMDP, модель коридору лекції.

</Figure>


- **POMDP** (*partially observable Markov decision process*) — MDP, у якому агент бачить спостереження, а не стан.
- **Стохастична гра** (*stochastic game*) — кілька агентів, кожен бачить стан, винагорода в кожного своя.
- **POSG** (*partially observable stochastic game*) — стохастична гра зі спостереженнями замість стану.
- **Dec-POMDP** (*decentralized POMDP*) — POSG зі спільною винагородою: так формулюють більшість задач рою.

Окремий випадок без станів — **гра в нормальній формі**: одна одночасна зустріч. З неї почнемо.

### Гра в нормальній формі: одна зустріч

Одна зустріч біля кишені: кожен один раз вирішує, звертати чи ні.

$$\Gamma = \big(I,\ \{A_i\},\ \{R_i\}\big), \qquad R_i : A_1\times\dots\times A_n \to \mathbb{R}$$

$I$ — агенти, $A_i$ — дії агента $i$, $R_i(a)$ — його винагорода за спільну дію $a = (a_1,\dots,a_n)$. Підручник (Albrecht et al., рис. 4.3) задає таку зустріч грою «хто зверне» (*Chicken*): S — не звертати, L — звернути.

| **агент 1 \ агент 2** | **S** | **L** |
|---|---|---|
| **S** | 0, 0 | 7, 2 |
| **L** | 2, 7 | 6, 6 |

Числа — умовні бали з підручника: 7 — пройшов першим, 2 — поступився, 6 — обидва звернули, 0 — зіткнення. Наприклад, $R_1(S, L) = 7$, $R_2(S, L) = 2$. Якщо зустріч повторюється, це **повторювана гра** (*repeated game*), і політика може залежати від історії.

### Стохастична гра: у кожному стані своя матриця

Увесь політ — низка кроків, і після кожного стан змінюється. Стохастична гра додає до нормальної форми стани $S$, переходи $T(s'\mid s,a)$ і початковий розподіл $\mu$:

$$G = \big(I,\ S,\ \{A_i\},\ \{R_i\},\ T,\ \mu\big)$$

У коридорі $S$ — 43 пари місць, $T$ детермінований (1 або 0), $\mu\big((0,4)\big) = 1$, а $R_i(s,a,s')$ — −1 за кожен дрон у коридорі й −50 за зіткнення. Тут $R_1 = R_2$ — спільна винагорода коридору; стохастична гра цього не вимагає.

Кожен стан можна читати як окрему матрицю: «виплата» спільної дії $a$ — винагорода кроку плюс найкраща віддача з наступного стану, $Q^*(s,a) = r + V^*(s')$. Ось матриця стану (1, 3), коли дрони стоять по обидва боки від кишені:

| **синій \ помаранчевий** | **вперед** | **чекати** | **кишеня** |
|---|---|---|---|
| **вперед** | −50 | **−11** | **−11** |
| **чекати** | **−11** | −13 | −13 |
| **кишеня** | **−11** | −13 | −13 |

Обидва вперед — зіткнення, −50. Обидва чекають — втрачений крок, −13. Найкраще −11: уперед летить **рівно один** («кишеня» поза клітинкою 2 — те саме, що «чекати»). Хто саме — матриця не каже: це гра координації, до якої повернемося в частині 5.


*Продовження блоку «Коридор: два дрони, повна модель і один крок»: цей код виконується разом із ним.*

<CodeFold title="Коридор як стохастична гра: оптимум і матриця одного стану" :lines="35" sec="0.1" check>

```python
# продовження блоку «Коридор: два дрони»
def solve(allowed):
    """Ітерація за цінністю для спільної винагороди (γ = 1) на дозволених діях."""
    V = {s: 0.0 for s in STATES}
    for _ in range(50):
        for s in STATES:
            if s != (HOME, HOME):
                V[s] = max(q(V, s, a) for a in allowed)
    return V


def q(V, s, a):
    """Цінність спільної дії a в стані s, якщо далі обидва діють найкраще."""
    s2, r, d = step(s, a)
    return r + (0 if d else V[s2])


V = solve(JOINT)
print(f"найкраща спільна віддача зі старту {START}: {V[START]:+.0f}")
for who, other in (("синій", 1), ("помаранчевий", 0)):
    allowed = [a for a in JOINT if a[other] != 2]  # другому кишеня заборонена
    W, s, path = solve(allowed), START, []
    while s != (HOME, HOME):
        a = max(allowed, key=lambda a: q(W, s, a))
        path.append(f"{ACTS[a[0]][:3]}/{ACTS[a[1]][:3]}")
        s = step(s, a)[0]
    print(
        f"пірнає {who}: віддача {W[START]:+.0f}, {len(path)} кроків: " + ", ".join(path)
    )
s = (1, 3)
print(f"стан {s}: Q*(a0, a1) = r + V*(s′); рядок — синій, стовпець — помаранчевий")
for a0 in range(3):
    print(
        f"{ACTS[a0]:>7s} " + " ".join(f"{q(V, s, (a0, a1)):+5.0f}" for a1 in range(3))
```

### POSG і Dec-POMDP: кортеж

POSG додає до стохастичної гри спостереження:

$$\big(I,\ S,\ \{A_i\},\ \{O_i\},\ \{\Omega_i\},\ \{R_i\},\ T,\ \mu\big)$$

| **Символ** | **Значення** | **У коридорі** |
|---|---|---|
| $O_i$ | спостереження агента $i$ | своє місце й місце іншого або «не видно» |
| $\Omega_i(o_i\mid a,s')$ | імовірність отримати $o_i$, якщо дія $a$ привела в $s'$ | 1 для того, що бачить сенсор радіусом 1 |

Не бачачи стану, агент може тримати **стан переконань** (*belief state*) — імовірності того, де зараз інший дрон; це та сама задача оцінювання стану, що у фільтрі Калмана з модуля 02. У Dec-POMDP до цього додається умова $R_1 = \dots = R_n$: винагорода одна на всіх.

### Рівновага Неша на пальцях

**Рівновага Неша** — пара дій, від якої жодному агентові не вигідно відхилитися самому. **Найкраща відповідь** (*best response*) — дія, найкраща проти фіксованої дії іншого.

Перевірка — два кроки:

1. У кожному стовпці підкресліть найбільше **перше** число: це найкраща відповідь агента 1 на дію агента 2.
2. У кожному рядку підкресліть найбільше **друге** число: це найкраща відповідь агента 2.

Клітинка, де підкреслено обидва числа, — рівновага: кожен агент уже грає найкращу відповідь на дію іншого.

```python
import itertools

import numpy as np


def pure_nash(R1, R2, names1, names2):
    """Повертає всі пари, від яких жодному агентові не вигідно відхилитись."""
    eq = []
    for i, j in itertools.product(range(R1.shape[0]), range(R1.shape[1])):
        best1 = R1[i, j] >= R1[:, j].max()  # агент 1 не покращить, змінивши рядок
        best2 = R2[i, j] >= R2[i, :].max()  # агент 2 не покращить, змінивши стовпець
        if best1 and best2:
            eq.append(f"({names1[i]},{names2[j]}) -> ({R1[i, j]:+d},{R2[i, j]:+d})")
    return eq


RPS1 = np.array([[0, -1, 1], [1, 0, -1], [-1, 1, 0]])
GAMES = {  # виплати агента 1 (рядок), агента 2 (стовпець), назви дій
    "Prisoner's Dilemma": ([[-1, -5], [0, -3]], [[-1, 0], [-5, -3]], "CD"),
    "Stag Hunt": ([[4, 0], [3, 2]], [[4, 3], [0, 2]], "SH"),
    "Chicken": ([[0, 7], [2, 6]], [[0, 2], [7, 6]], "SL"),
    "Battle of the Sexes": ([[10, 2], [0, 7]], [[7, 2], [0, 10]], "AB"),
    "Rock-Paper-Scissors": (RPS1, -RPS1, "RPS"),
}
for name, (R1, R2, acts) in GAMES.items():
    eq = pure_nash(np.array(R1), np.array(R2), acts, acts)
    found = "; ".join(eq) or "детермінованих рівноваг немає"
    print(f"{name:22s} {found}")
```

### Імовірнісні рівноваги: умова байдужості

**Імовірнісна політика** (*mixed strategy*) обирає дію навмання з певними ймовірностями. Нехай агент 2 у «хто зверне» обирає S з імовірністю $q$. Тоді середня винагорода агента 1 за кожну його дію:

$$\text{S:}\ \ 0\cdot q + 7\,(1-q) = 7 - 7q$$

$$\text{L:}\ \ 2\,q + 6\,(1-q) = 6 - 4q$$

Агент 1 змішує дії лише тоді, коли йому однаково — це **умова байдужості**:

$$7 - 7q = 6 - 4q \quad\Rightarrow\quad q = \tfrac{1}{3}$$

Тоді кожна дія дає $7 - \tfrac{7}{3} = \tfrac{14}{3} \approx 4{,}67$.


<Figure src="/figs/own/mod06-mixed.png" msrc="/figs/own/mod06-mixed-m.png" alt="Середня винагорода агента 1 у грі «хто зверне» залежно від імовірності q, з якою агент 2 не звертає: пряма 7 − 7q для дії S і пряма 6 − 4q для дії L перетинаються при q = 1/3, де обидві дії дають 14/3 ≈ 4,67.">

Середня винагорода агента 1 у грі «хто зверне» залежно від імовірності q, з якою агент 2 не звертає: пряма 7 − 7q для дії S і пряма 6 − 4q для дії L перетинаються при q = 1/3, де обидві дії дають 14/3 ≈ 4,67.

</Figure>


Імовірність кожного агента підбирають так, щоб байдужим став *інший*: $q$ агента 2 вирівнює дії агента 1, $p$ агента 1 — дії агента 2. Гра симетрична, тож і $p = 1/3$. Ліворуч від перетину агенту 1 вигідніше S, праворуч — L; у точці перетину йому однаково, тож будь-яке змішування — його найкраща відповідь.

| **Гра** | **Рівняння байдужості** | **Імовірнісна рівновага** |
|---|---|---|
| полювання на оленя | $4q = 3q + 2(1-q)$ | $q = 2/3$, по 2,67 |
| битва статей | $10q + 2(1-q) = 7(1-q)$ і $7p = 2p + 10(1-p)$ | агент 2 обирає A з $q = 1/3$, агент 1 — з $p = 2/3$; по 4,67 |
| камінь–ножиці–папір | кожна дія проти 1/3, 1/3, 1/3 дає 0 | 1/3 на кожну дію, значення 0 |
| дилема в'язня | D краща за будь-якого $q$ | немає: D домінує |

Віджет дає покрутити $p$ і $q$ в іграх 2 × 2 і побачити, коли обидві дії стають однаково вигідними.

```python
# продовження блоку «Шукає детерміновані рівноваги»
def mixed_2x2(R1, R2):
    """p — агент 1 грає перший рядок, q — агент 2 грає перший стовпець.

    q робить агенту 1 байдужим вибір рядка, p робить агенту 2 байдужим
    вибір стовпця. Повертає p, q і очікувані виплати обох.
    """
    A, B = np.array(R1, float), np.array(R2, float)
    q = (A[1, 1] - A[0, 1]) / (A[0, 0] - A[0, 1] - A[1, 0] + A[1, 1])
    p = (B[1, 1] - B[1, 0]) / (B[0, 0] - B[1, 0] - B[0, 1] + B[1, 1])
    x, y = np.array([p, 1 - p]), np.array([q, 1 - q])
    return p, q, x @ A @ y, x @ B @ y


print("гра                       p      q    U1     U2")
for name, (R1, R2, _) in list(GAMES.items())[:4]:
    p, q, u1, u2 = mixed_2x2(R1, R2)
    if 0 <= p <= 1 and 0 <= q <= 1:
        print(f"{name:22s} {p:6.3f} {q:6.3f} {u1:5.2f} {u2:6.2f}")
    else:
        print(f"{name:22s} імовірнісної рівноваги немає: D домінує")
third = np.full(3, 1 / 3)  # Rock-Paper-Scissors: кожна дія з імовірністю 1/3
print("RPS проти 1/3, 1/3, 1/3: виплата кожної дії", np.array(RPS1) @ third)
mix = np.array([1 / 2, 1 / 4, 1 / 4])  # агент 1 відступив від 1/3, 1/3, 1/3
print("RPS, агент 1 грає (1/2, 1/4, 1/4): виплата проти R, P, S =", mix @ RPS1)
```

## Частина 3 · Концепції розв'язку

Розв'язок гри — **спільна політика** $\pi = (\pi_1,\dots,\pi_n)$, по одній на агента. Ця частина дає кожному критерію формулу й таблицю на іграх лекції.

### Очікувана віддача й найкраща відповідь

Коли обидва змішують дії, кожна клітинка трапляється з імовірністю «імовірність рядка × імовірність стовпця». Очікувана віддача — сума винагород, зважених цими ймовірностями:

$$U_1(\pi) = \sum_{a} R_1(a)\cdot\Pr(a)$$

«Хто зверне», $p = q = 1/3$:

| **Клітинка** | **Імовірність** | **$R_1$** | **Внесок** |
|---|---|---|---|
| (S, S) | $\tfrac13\cdot\tfrac13 = \tfrac19$ | 0 | 0 |
| (S, L) | $\tfrac13\cdot\tfrac23 = \tfrac29$ | 7 | $\tfrac{14}{9}$ |
| (L, S) | $\tfrac23\cdot\tfrac13 = \tfrac29$ | 2 | $\tfrac{4}{9}$ |
| (L, L) | $\tfrac23\cdot\tfrac23 = \tfrac49$ | 6 | $\tfrac{24}{9}$ |
| **разом** | 1 | | $\tfrac{42}{9} \approx 4{,}67$ |

У стохастичній грі віддачу рахують по всьому польоту з дисконтом $\gamma$: $U_i(\pi) = \mathbb{E}\big[\sum_t \gamma^t R_i(s^t,a^t,s^{t+1})\big]$.

**Найкраща відповідь** тепер — політика, що максимізує віддачу проти фіксованих політик інших, позначених $\pi_{-i}$:

$$BR_i(\pi_{-i}) = \arg\max_{\pi_i} U_i(\pi_i,\pi_{-i})$$

### Рівновага Неша в загальному вигляді

Те, що ми підкреслювали в матриці, у загальному вигляді записують так:

$$U_i(\pi_i',\pi_{-i}) \le U_i(\pi) \quad \text{для кожного агента } i \text{ і кожної його політики } \pi_i'$$

Тобто політика кожного агента — найкраща відповідь на політики решти. Для «хто зверне» умову виконують три спільні політики: (S, L), (L, S) і обидва з імовірністю 1/3 обирають S.

Неш довів (1950), що рівновага є в кожній скінченній грі, можливо, лише ймовірнісна. Знайти її загалом важко: задача PPAD-повна (Daskalakis et al., 2009) — розв'язок існує, але ефективного алгоритму для будь-якої гри не відомо. Тому MARL не шукає рівновагу точно, а навчається достатньо доброї спільної політики.

### Мінімакс на «камені–ножицях–папері»

У грі двох агентів з нульовою сумою є простіший погляд — **мінімакс**: гарантія проти найгіршого. Агент 1 дивиться, що найгірше дає кожна його дія, і обирає найкращий із цих найгірших результатів.

| **агент 1 \ агент 2** | **камінь** | **папір** | **ножиці** | **найгірше в рядку** |
|---|---|---|---|---|
| **камінь** | 0 | −1 | 1 | −1 |
| **папір** | 1 | 0 | −1 | −1 |
| **ножиці** | −1 | 1 | 0 | −1 |
| **1/3 на кожну дію** | 0 | 0 | 0 | **0** |

Будь-яка одна дія гарантує лише −1. Рівномірна політика гарантує 0 проти будь-кого — це найкраща гарантія, **значення гри**:

$$\max_{\pi_1}\ \min_{\pi_2}\ U_1(\pi_1,\pi_2) = 0$$

Відхилення суперник використає: якщо агент 1 грає (1/2, 1/4, 1/4), то проти паперу отримує $\tfrac12\cdot(-1) + \tfrac14\cdot 0 + \tfrac14\cdot 1 = -0{,}25$. Що для ймовірнісних політик $\max\min$ дорівнює $\min\max$, довів фон Нейман (1928); Шеплі (1953) поширив це на стохастичні ігри з нульовою сумою.

### Парето, добробут і справедливість

Рівновага питає, чи хоче хтось змінити дію сам. Інші критерії дивляться на результат для всіх:

- **Парето-оптимальна** клітинка — та, яку не можна покращити одному, не погіршивши іншому;
- **добробут** (*welfare*) — сума віддач, $W = U_1 + U_2$;
- **справедливість** (*fairness*) — добуток, $F = U_1\cdot U_2$, має сенс за додатних віддач.

```python
import numpy as np

EPISODES, T_MAX, ALPHA, SEEDS = 3000, 20, 0.1, range(5)  # обрано до прогону
KEY = {"CQL": lambda i, s: s, "IQL": lambda i, s: s, "IQL, сенсор 1": see}


def train(kind, seed):
    """CQL: одна таблиця на 9 спільних дій. IQL: у кожного дрона своя на 3 дії."""
    rng = np.random.default_rng(seed)
    n, tabs = (9, 1) if kind == "CQL" else (3, 2)
    Q = [{} for _ in range(tabs)]

    def q(i, s):
        return Q[i].setdefault(KEY[kind](i, s), np.zeros(n))

    def act(s, e):
        idx = [
            rng.integers(n) if rng.random() < e else int(np.argmax(q(i, s)))
            for i in range(tabs)
        ]
        return idx, JOINT[idx[0]] if kind == "CQL" else tuple(idx)

    curve, updates = [], [0] * tabs
    for ep in range(1, EPISODES + 1):
        s, e = START, max(0.05, 1 - ep / 1000)  # ε спадає від 1 до 0,05
        for _ in range(T_MAX):
            idx, a = act(s, e)
            s2, r, done = step(s, a)
            for i in range(tabs):  # кожна таблиця вчиться на спільній винагороді r
                target = r + (0 if done else q(i, s2).max())
                q(i, s)[idx[i]] += ALPHA * (target - q(i, s)[idx[i]])
                updates[i] += 1
            s = s2
            if done:
                break
        if ep % 100 == 0:  # жадібний політ зі старту без дослідження
            s, ret = START, 0.0
            for _ in range(T_MAX):
                s, r, done = step(s, act(s, 0)[1])
                ret += r
                if done:
                    break
            curve.append((ret, s == (HOME, HOME)))
    return np.array(curve), updates, Q


print("спосіб         розійшлися з 5 і середня віддача після")
print(" " * 15 + "500        1000        1500        3000")

    )
```

## Частина 5 · Чотири виклики MARL

Чотири властивості багатоагентної задачі, через які одноагентні рецепти не переносяться напряму. Кожну подано однаково: що це, приклад, число з прогону і що з цим роблять.

### Виклик 1: нестаціонарність

**Що це.** Для агента інші агенти — частина середовища, а вони теж учаться, тож середовище змінюється під ним. Формально динаміка, яку бачить агент $i$, — справжня, усереднена за політиками інших:

$$T_i(s'\mid s,a_i) = \sum_{a_{-i}} T\big(s'\mid s,\langle a_i,a_{-i}\rangle\big)\prod_{j\ne i}\pi_j(a_j\mid s)$$

Q-навчання сходиться, лише якщо $T$ не змінюється, — а тут $\pi_j$ змінюється з кожним епізодом.

**Приклад.** Полювання на оленя: агент 1 бачить середню винагороду своєї дії залежно від імовірності $q$, з якою агент 2 обирає S:

$$\tilde R_1(S) = 4q, \qquad \tilde R_1(H) = 3q + 2(1-q) = 2 + q$$

**Число.** Найкраща дія агента 1 перемикається при $4q = 2 + q$, тобто $q = 2/3$: за $q = 0{,}2$ краща H (2,2 проти 0,8), за $q = 0{,}9$ — S (3,6 проти 2,9). Агент 1 нічого не змінював — змінився агент 2.

### Нестаціонарність у прогоні

Два мисливці навчаються незалежним Q-навчанням. Стану немає, тож кожен вчить лише два числа — $Q(S)$ і $Q(H)$ — і після кожного раунду оновлює одне з них:


<CodeFold title="Незалежне Q-навчання: одне оновлення двох агентів" :lines="17" sec="0.1">

```python
import numpy as np

np.set_printoptions(precision=2, floatmode="fixed")  # друкуємо Q з двома знаками
ALPHA = 0.1
R = np.array([[4, 0], [3, 2]])  # Stag Hunt: R[моя дія, дія іншого], дії S = 0, H = 1
Q1, Q2 = np.zeros(2), np.zeros(2)  # кожен агент знає лише свої дві оцінки


def update(Q, my, other):
    """Q(моя дія) ← Q + α·(r − Q): дію іншого агент не бачить, лише свою винагороду."""
    Q[my] += ALPHA * (R[my, other] - Q[my])


for a1, a2 in [(1, 0), (1, 1)]:  # раунд 1: H проти S; раунд 2: H проти H
    update(Q1, a1, a2)
    update(Q2, a2, a1)
    print(f"дії ({'SH'[a1]}, {'SH'[a2]}): Q1 = {Q1}, Q2 = {Q2}")
```

<CodeFold title="Незалежне Q-навчання на Stag Hunt на п'яти зернах" :lines="42" sec="0.4" check>

```python
import numpy as np

EPS, ALPHA, ROUNDS, SEEDS = 0.1, 0.1, 2000, range(5)  # обрано до прогону


def greedy(q, rng):
    return int(rng.choice(np.flatnonzero(q == q.max())))  # нічию розбиває жереб


def iql(R1, R2, seed, q0=0.0):
    """Незалежне Q-навчання двох агентів у повторюваній матричній грі.

    Кожен агент знає лише власні дії та винагороди. Повертає журнал:
    жадібна дія кожного агента й Q обох після кожного раунду.
    """
    rng = np.random.default_rng(seed)
    Q, log, updates = [np.full(2, q0), np.full(2, q0)], [], [0, 0]
    for _ in range(ROUNDS):
        a = [
            rng.integers(2) if rng.random() < EPS else greedy(Q[i], rng) for i in (0, 1)
        ]
        r = (R1[a[0], a[1]], R2[a[0], a[1]])
        for i in (0, 1):
            Q[i][a[i]] += ALPHA * (r[i] - Q[i][a[i]])  # Q ← Q + α(r − Q)
            updates[i] += 1
        log.append([int(Q[0][1] > Q[0][0]), int(Q[1][1] > Q[1][0]), *Q[0], *Q[1]])
    return np.array(log), updates


SH1, SH2 = np.array([[4, 0], [3, 2]]), np.array([[4, 3], [0, 2]])  # дії: S, H
print(f"ε = {EPS}, α = {ALPHA}, раундів {ROUNDS}, зерен {len(SEEDS)}")
counts = set()  # скільки разів оновився кожен агент — в усіх 10 прогонах
for q0 in (0.0, 5.0):
    ends = []
    for seed in SEEDS:
        log, upd = iql(SH1, SH2, seed, q0)
        counts.add(tuple(upd))
        pair = "".join("SH"[int(x)] for x in log[-1, :2])  # кінцеві жадібні дії
        flips = np.flatnonzero(np.any(np.diff(log[:, :2], axis=0) != 0, axis=1))
        ends.append(f"{pair} з раунду {flips[-1] + 2 if len(flips) else 1}")
    print(f"Q0 = {q0}: {ends}")
print(f"оновлень на агента, усі 10 прогонів: {sorted(counts)}")
```

### Виклик 3: розподіл заслуг

**Що це.** Зі спільною винагородою кожен отримує одне число на всіх і не знає, чи був корисним сам (*credit assignment*). У коридорі обидва дрони отримують −13, хоча поступався лише той, хто пірнав у кишеню.

**Приклад.** Чотири БПЛА обстежують три сектори цінністю A — 3, B — 2, C — 1,5; виліт коштує 0,3 енергії, сектор зараховують один раз. БПЛА 1 летить в A, БПЛА 2 і 3 — в B, БПЛА 4 лишається на базі. **Різницева винагорода** (*difference reward*) порівнює спільну винагороду з тією, що була б, якби агент лишився на базі:

$$D_i = G(a) - G\big(\langle \text{база}_i,\ a_{-i}\rangle\big)$$


<Figure src="/figs/own/mod06-credit.png" msrc="/figs/own/mod06-credit-m.png" alt="Ліворуч — план польоту: БПЛА 1 у секторі A, БПЛА 2 і 3 у секторі B, сектор C порожній, БПЛА 4 на базі. Посередині — спільна винагорода 4,1, однакова для всіх. Праворуч — різницеві винагороди: +2,7, −0,3, −0,3 і 0.">

Ліворуч — план польоту: БПЛА 1 у секторі A, БПЛА 2 і 3 у секторі B, сектор C порожній, БПЛА 4 на базі. Посередині — спільна винагорода 4,1, однакова для всіх. Праворуч — різницеві винагороди: +2,7, −0,3, −0,3 і 0.

</Figure>


**Число.** Спільна $G = 3 + 2 - 3\cdot 0{,}3 = 4{,}1$ однакова для всіх. Різницеві: БПЛА 1 — $4{,}1 - 1{,}4 = +2{,}7$; БПЛА 2 і 3 — по $-0{,}3$: другий апарат у B нічого не додає й лише витрачає енергію; БПЛА 4 — 0. Якби БПЛА 3 полетів у C, команда мала б найкращі 5,6.

**Що з цим роблять:**

- рахують різницеві винагороди в симуляторі, де можна «прибрати» агента;
- навчають централізованого критика, що оцінює внесок кожного (модуль 08);
- розкладають спільну цінність на суму внесків агентів (модуль 09).


<CodeFold title="Різницеві винагороди для чотирьох БПЛА" :lines="27" sec="0.0" check>

```python
import itertools

VALUE = {"A": 3.0, "B": 2.0, "C": 1.5}  # цінність обстеження сектора
COST, BASE = 0.3, "база"  # енергія за виліт; дія за замовчуванням — лишитися на базі


def team_reward(plan):
    """Спільна винагорода: цінність покритих секторів мінус енергія вильотів."""
    covered = {sector for sector in plan if sector != BASE}
    flying = sum(sector != BASE for sector in plan)
    return sum(VALUE[s] for s in covered) - COST * flying


def difference(plan, i):
    """D_i = G(a) − G(a з дією агента i, заміненою на «база»)."""
    without = list(plan)
    without[i] = BASE
    return team_reward(plan) - team_reward(without)


plan = ["A", "B", "B", BASE]  # куди полетіли БПЛА 1–4
G = team_reward(plan)
print(f"план {plan}: спільна винагорода G = {G:.1f} — її отримує кожен")
for i, sector in enumerate(plan):
    print(f"БПЛА {i + 1} ({sector:4s}): D = {difference(plan, i):+.1f}")
best = max(itertools.product([*VALUE, BASE], repeat=4), key=team_reward)
print(f"найкращий план {list(best)}: G = {team_reward(best):.1f}")
```

### Висновки

- Моделі ігор відрізняються відповідями на три питання: скільки агентів, стан чи спостереження, своя чи спільна винагорода. Коридор лекції з сенсором — Dec-POMDP, з повним станом — стохастична гра зі спільною винагородою.
- Рівновага Неша — клітинка, де підкреслено обидві найкращі відповіді. Їх буває кілька, вона буває гіршою за нерівноважну клітинку, а в «камені–ножицях–папері» є лише ймовірнісна.
- Імовірнісну рівновагу дає умова байдужості: у «хто зверне» $q = 1/3$ і по 4,67.
- Парето не означає найбільшого добробуту: (S, L) дає 9, (L, L) — 12.
- У коридорі CQL дійшов до оптимуму −13 у всіх зернах; IQL розходиться раніше, але в середньому зупиняється на −15.
- Чотири виклики: нестаціонарність ($q = 2/3$), вибір рівноваги (5 зерен із 5 у безпечній (H, H)), розподіл заслуг (спільні 4,1 проти різницевих +2,7 / −0,3 / −0,3 / 0), масштабування (6⁸ ≈ 1,7 млн спільних дій).

### Довідка: типи ігор і словник

| **Тип гри** | **Задача рою** | **Головна складність** |
|---|---|---|
| з нульовою сумою, 2 агенти | перехоплення, ухилення | гарантія проти найгіршого |
| зі спільною винагородою (Dec-POMDP) | обстеження, доставка, коридор лекції | розподіл заслуг, хто поступиться |
| полювання на оленя | маневр, що вдається лише разом | вигідна чи безпечна рівновага |
| «хто зверне» | прохід з окремими винагородами | обидва не поступляться |
| битва статей | спільна точка збору чи частота | дві детерміновані рівноваги |
| загальна сума, $n$ агентів | кілька операторів в одному просторі | кооперація й конкуренція водночас |

Ті самі поняття в теорії ігор називають інакше: середовище — гра (*game*), агент — гравець (*player*), винагорода — виплата (*payoff*), політика — стратегія (*strategy*), детермінована — чиста (*pure*), імовірнісна — змішана (*mixed*), спільна дія — профіль дій (*action profile*).

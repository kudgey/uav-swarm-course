## Локальний запуск

```bash
npm install
npm run dev        # режим розробки
npm run build      # статична збірка
npm run preview    # подивитися зібране
```

Або подвійний клік по **«Відкрити курс.command»** — підніметься локальний сервер
і відкриється браузер. Інтернет не потрібен: рисунки, шрифти й формули лежать поруч.

Клавіша <kbd>P</kbd> вмикає режим презентації для проєктора.

## Збірка сторінок із джерел

Джерело правди — markdown-файли лекцій. Конвертер робить із кожної картки
розділ сторінки:

```bash
python3 tools/build_site.py        # усі 10 сторінок
python3 tools/run_examples.py      # запустити приклади коду й звірити вивід
```

Формули MathJax предрендерені в SVG на етапі збірки, тому в готовому HTML
немає ані CDN, ані рантайм-бібліотеки.
